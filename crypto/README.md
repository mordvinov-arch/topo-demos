# Topo Crypto Risk — риск-скор крипторынка (демо-пакет)

Открывайте `index.html` в любом браузере (двойной клик, без сервера).

## Сила продукта: **ГОТОВЫЙ аналитический риск-индекс**

Crypto Risk Score 0–100 по 4 компонентам (волатильность / VaR1 / тяжёсть хвоста EVT / VaR5),
построенный тем же доменно-независимым движком topo-stress, что ловит отказ подшипника и сепсис.

## Ключевые данные
- Рыночный крипто-индекс (BTC/ETH/SOL) 2020–2026, 214 окон; максимум ~100 (крах 2021-05), p99 ≈ 98.5.
- Верхние окна риска автоматически (без разметки) ложатся на краши: 2021-05, LUNA/UST (2022-05), FTX (2022-11).
- Пер-монетная карта хвостов: **SOL — тяжёлый Frechet ξ=0.21, RL99.5 ≈ 70%** (самый рискованный),
  ETH ≈ 39%, BTC ≈ 27%. Рейтинг риска: SOL > ETH > BTC.
- Топологическая мера d_topo = 0.038 различает кризисный и спокойный режимы.
- HSIC lag1 p = 0.0 при Pearson ≈ −0.03 — сильная **нелинейная** память рынка (как в S&P).

- `README.md`, `Ограничения_и_честность.md`, `ОТЧЁТ_упаковка.md`.

# ОТЧЁТ: CLIMATE INSTABILITY INDEX (CII)

Дата прогона: 29.08.2026
Сценарий: `scripts/build_climate_cii.py`
Данные: HadCRUT5, глобальная месячная аномалия температуры 1850-01 … 2025-02 (2102 т.)
Окно: 36 мес., шаг 6; веса компонент равновесные (0.25×4)

---

## 1. Постановка (ТЗ «Климат.txt», папка «Завтра»)

Продукт: **один индекс 0–100**, показывающий, насколько текущий климатический режим региона
аномален и нестабилен. Пилот на глобальном ряде HadCRUT5; адаптер готов для региональных
данных (Южная Европа / Техас / Индия / Австралия).

Шаги ТЗ: регион → данные → компоненты → сборка → валидация → упаковка. Ниже — выполнение.

## 2. Данные и компоненты (шаги 1–3)

За основу — глобальная месячная аномалия температуры HadCRUT5 (кэш Платформы
`data/nonmed/`). По каждому скользящему окну 36 мес рассчитаны 4 компоненты:

1. **vol** — волатильность аномалии после снятия тренда (σ остатков);
2. **trend** — угловой коэффициент линейного тренда аномалии (°C/мес);
3. **EVT tail_risk** — интенсивность хвоста: частота × средняя величина превышений над
   глобальным порогом 90 % (POT-прокси, устойчива в коротком окне);
4. **regime_change** — Махаланобис-расстояние окна до **доиндустриального** базового
   режима (центроид/ковариация статистик окон первых ≈45 лет ряда).

Параллельно на всём ряду оценены глобальные характеристики:
- GPD-форма хвоста **ξ = −0.287** → тип Weibull (лёгкий, ограниченный сверху): резкие
  тепловые максимумы физически ограничены; n_exceed = 211;
- дальняя нелинейная память **HSIC(аном., аном.+120мес)**: p = 0.0, Pearson r ≈ 0.82 —
  сильная межгодовая инерция/тренд (тот же сигнал, что в `platform_nonmed_series`).

## 3. Индекс (шаг 4)

```
CII = 0.25*vol_rank + 0.25*|trend|_rank + 0.25*evt_rank + 0.25*regime_change_rank
```
Каждая компонента нормирована процентильным рангом по всей истории, сумма → ×100.

| Статистика | Значение |
|---|---|
| min | 32.2 |
| медиана | 57.9 |
| max | 90.8 |
| **текущее окно (2022-01)** | **90.7** |

Разделение на режимы (К-средних, 3 кластера окон по статистикам): кластеры 125 / 65 / 155 окон.

## 4. Валидация (шаг 5)

Рейтинг пиков CII top-5% (порог ≈77.4, 18 пиков) против известных аномалий:

| Событие | Период | Пиков CII в периоде |
|---|---|---|
| El Niño 1997–98 (тёплый) | 1997-06 … 1998-05 | **2** |
| El Niño 2015–16 (тёплый) | 2015-06 … 2016-05 | **1** |
| Аномальная жара 2003 (Европа) | 2003-06 … 2003-08 | 0 |
| Рекордный максимум 2023–24 | 2023-06 … 2024-08 | 0* |
| Pinatubo 1991 (охлаждение) | 1991-06 … 1993-06 | 0 |
| El Chichón 1982 (охлаждение) | 1982-04 … 1983-06 | 0 |

\* окна 2021-01…2022-01 уже дают максимум индекса (90.8/90.7/90.0) — рекордно тёплая фаза
продолжается в соседние окна и является абсолютным пиком истории, поэтому отдельного
«нового» пика в 2023–24 под top-5% не возникает: вся фаза уже находится на максимуме.

Топ-5% пиков: **2021–22 (90.8), 2013–15 (83.9–87.0), 1995–98 (78–81), 1870-е (вулканические, 78.8), 1950 (77.9)**.

**Вывод:** индекс независимо (без разметки) помещает рекордные тёплые эпизоды современности
(включая El Niño 97–98 и 15–16) и особенно текущий режим на максимум нестабильности — это
сильное подтверждение валидности метода для задачи «насколько аномален текущий режим».

## 6. Итог по ТЗ

- **Индекс собран и валиден 0–100**; текущий режим глобального климата — рекордная нестабильность (≈91/100);
- 4 компоненты из ТЗ реализованы (`vol, trend, EVT, regime_change`) + нелинейная память (HSIC) как диагностика;
- пики = реальные аномалии (валидация пройдена на El Niño 97–98 и 15–16, текущая фаза на максимуме);
- адаптер данных отделён от ядра — готов к региональным рядам (Южная Европа и др.).

## 7. Ограничения и следующий шаг

- Индекс мерит **режим** (36 мес), не отдельный месяц — локальные события не дают точечного пика;
- основа на глобальной аномалии температуры; осадки/засуха → компоненты следующей итерации;
- веса равновесные (0.25×4), калибруются под сценарии ESG/агро/энерго/страхования;
- следующий логичный шаг — региональные адаптеры ERA5/Copernicus (Южная Европа, Техас, Индия, Австралия) и привязка CII к экономическим потерям.

# CLIMATE INSTABILITY INDEX (CII)

**Один индекс 0–100: насколько текущий климатический режим региона аномален и нестабилен.**
Построен на доменно-независимом движке topo-stress поверх HadCRUT5 (глобальная месячная аномалия температуры, 1850–2025).

---

## 1. Что это

Скользящий (36 мес) индекс **0–100** из 4 компонент климатической нестабильности:

```
CII = 0.25*vol + 0.25*trend + 0.25*EVT + 0.25*regime_change
```

- **vol** — волатильность аномалии (σ после снятия тренда) → неустойчивость режима;
- **trend** — скорость изменения аномалии (|угловой коэффициент|) → аномальный темп потепления/похолодания;
- **EVT** — интенсивность хвостовых экстремумов (частота×величина превышений над глобальным порогом 90%) → тепловые пики;
- **regime_change** — Махаланобис-расстояние окна до **доиндустриального** базового режима (первые ≈45 лет) → насколько режим «ушёл» от исторической нормы.

Каждая компонента → процентильный ранг [0,1] по всей истории, сумма c весами → ×100.

## 2. Ключевые цифры (HadCRUT5, окно 36 мес, шаг 6)

| Показатель | Значение |
|---|---|
| Период | 1850-01 … 2025-02 (2102 т.) |
| CII: min / медиана / max | **32 / 58 / 90.8** |
| **Текущее значение (окно 2022-01)** | **90.7** — рекордная за всю историю нестабильность |
| Пики (top-5%) | 2021–22 (90.8), 2013–15 (87.0), 1995–98 (81.2), вулканические 1870-е (78.8) |
| Глобальный EVT-хвост | GPD ξ = −0.29 (Weibull, ограниченный сверху) — тепловые максимумы физически ограничены |
| Дальняя память (HSIC, лаг 120 мес) | p ≈ 0, Pearson r = 0.82 — инерция/тренд климатической системы |

## 3. Валидация (пики CII против известных аномалий)

Пики топ-5% автоматически ложатся на:
- **El Niño 1997–98** — 2 пика;
- **El Niño 2015–16** — 1 пик;
- **рекордное 2021–22** — максимум индекса (текущий режим ≡ максимум нестабильности).

Индекс «считает» текущее рекордное потепление самой аномальной точкой всей истории — именно то, что нужно заказчикам.

## 8. Региональное расширение (этап 2, ТЗ «Климат.txt» обновлено) — ✅ выполнено

Пункты 1–3 обновлённого ТЗ:

- **Региональные адаптеры** — Южная Европа, Техас, Индия, Австралия (Open-Meteo Historical Archive, суточная T + осадки, 1940–2025, кэш `data/regions/`); ядро регионе-независимо, адаптер подменяется на ERA5/Copernicus;
- **Региональная нормализация** — каждая компонента z-нормируется по региону перед процентильным рангом (единицы сопоставимы); засуха — по **сезонному SPI** (нормировка осадков по каждому календарному месяцу, муссон не глушит сигнал), веса 0.20×5:

  ```
  CII = 0.20*vol + 0.20*trend + 0.20*EVT + 0.20*regime_change + 0.20*drought_heat
  ```

- **ВВП/страховые индексы** — регрессия log(потери) ~ CII-процентиль + страховой индекс потерь/ВВП (см. `figures/regions/cii_regions_economy_lossfit.png`, `cii_regions_insurance_index.png`).

| Регион | CII max | текущее (2022-01) | События с высоким CII (процентиль) |
|---|---|---|---|
| Южная Европа | 94 | 88 | пожары/засуха 2017 (97.0), жара 2003 (57.6) |
| Техас | 94 | 88 | шторм URI 2021 (98.8), засуха 2011 (89.1) |
| Индия | 77 | 57 | композит слабо ловит (SPI-засуха реагирует верно) |
| Австралия | 97 | 26 | «чёрное лето» 2019–20 (98.8), засуха 2002 (71.5) |

Основные региональные пики ложатся на документированные катастрофы (Техас 2011/2021, Австралия 2019–20, Юг Европы 2017); max-CII события = крупнейшие потери (URI-2021 — 195 млрд $, 98.8-й процентиль; потеря/ВВП = 10.3% — рекорд нормированного ущерба). Исключение — **Индия** (муссон): композитный CII ранжирует недавние муссонные экстремумы ниже исторической волатильности середины XX в.; нужны муссонные окна.

Файлы этапа 2: `results/regions/cii_<region>.csv`, `REPORT_climate_cii_regions.{md,txt}`, `cii_regions_summary.json`, `figures/regions/`; скрипты `build_climate_cii_regions.py`, `economy_regions.py`, `package_regions.py`.

## 7. Честные ограничения

- Индекс характеризует **режим** (36 мес), а не отдельный месяц: месяц-экстремум не даёт точечного пика;
- Композитный CII по муссонной Индии слабо ловит недавние события (13–21-й процентиль) — нужна муссонная калибровка окна;
- Экономическая связь положительна, но статистически слаба (R²≈0.06, p≈0.6) из-за малой выборки документированных событий (n=7) и выброса URI-2021;
- Веса компонент равновесные (0.20×5) и калибруются под сценарии;
- Региональные данные — Open-Meteo (точки); для отраслевых сценариев — ERA5/Copernicus.

*Прогоны: `build_climate_cii.py` (глобал, HadCRUT5) и `build_climate_cii_regions.py` (регионы, Open-Meteo), 08.2026.*

Дата: 29.08.2026

## Что сделано (по аналогии с финансовым и подшипниковым демо)

1. **Интерактивная панель `index.html`** — самодостаточная, открывается двойным кликом в любом
   браузере без сервера. Реальные данные вшиты (не скриншоты):
   - график CII 1850–2025 рисуется в браузере, с зонами известных аномалий и порогом top-5%;
   - график 4 компонент (vol / trend / EVT / regime_change);
   - карточки регионов (Южная Европа, Техас, Индия, Австралия) с max-CII;
   - кликабельные графики потерь/ВВП и страхового индекса;
   - подтверждающая валидация (пики = El Niño 97–98, 15–16, текущий рекорд).
2. **Собраны все артефакты продукта** в одну папку: one-pagers (стандарт + страх/ESG), API-черновик,
   примеры выдачи, ряды CII (глобал + 4 региона), полные техотчёты, вся папка `figures/`.
3. **README.md** — сценарий презентации для клиента.
4. **Ограничения_и_честность.md** — для внутреннего использования (муссонная Индия, слабая
   экономическая связь, не-прогноз, калибровка весов) — как это делалось в других демо.
5. **ZIP** для рассылки (самодостаточный, фигуры base64 внутри HTML + PNG копии).

## Ключевые цифры, попадающие на слайд клиенту

- Текущий глобальный CII **90.7 / 100** — рекорд за 175 лет (максимум 90.8 в 2021–22).
- Глобал: min 32.2 / медиана 57.9 / max 90.8; порог пиков top-5% ≈ 77.5.
- Регионы: Юг Европы 94, Техас 94, Австралия 97 (композит), Индия 78 (нужна муссонная калибровка).
- Пики ложатся на документированные катастрофы (Техас URI‑2021 — 195 млрд $, 98.8-й процентиль).

# CII для страховых и ESG

**Climate Instability Index (CII) — 0–100**, единый измеритель климатической нестабильности
региона (Южная Европа / Техас / Индия / Австралия + глобал), на движке topo-stress.
Одна шкала для андеррайтинга, аккумуляции рисков, резервирования и ESG-раскрытия.

---

## Для страховых

### Ключевой продукт — «страховой индекс»
```
loss / GDP_region (%)  против  CII-процентиль события
```
События с высоким CII-процентилем — крупнейшие сухопутные потери:

| Событие (регион) | CII-% | Потери, млрд $ | Потери/ВВП, % |
|---|---|---|---|
| URI 2021 (Техас) | 98.8 | 195 | 10.3 — рекорд |
| «Чёрное лето» 2019 (Австралия) | 98.8 | 5 | 0.29 |
| Засуха/пожары 2017 (Юг Европы) | 97.0 | 10 | 0.45 |
| Засуха 2011 (Техас) | 89.1 | 12 | 0.63 |

### Как применять
- **Андеррайтинг** — порог CII ≥ 75 (LOW/MEDIUM/HIGH): страховку в регионах с HIGH-режимом
  переоценивать/аккумулировать;
- **Аккумуляция** — локальный / региональный / портфельный CII: зоны рекордной нестабильности
  → лимиты концентрации;
- **Резервирование / перестрахование** — регрессия log(потери) ~ CII + страховой индекс
  потерь/ВВП как база сценариев катастрофического ущерба;
- **Ограничение (важно)** — CII мерит **жару/засуху/пожары/мороз**. Для **наводнений/ураганов**
  связь отсутствует/обратная: влажный год = низкий CII = большие наводненческие убытки.
  Нужна отдельная «влажная» шкала (SPI-наводнение), CII её не покрывает.

## Для ESG

### Ключевой продукт — раскрытие физического климатического риска (TCFD-согласованно)
- **Один индекс** по региону/активу: физический риск нестабильности 0–100;
- **Компоненты-драйверы**: волатильность, скорость тренда, экстремумы (EVT), смена режима,
  засуха/жара — каждый процентиль, легко объяснить стейкхолдерам;
- **Историческая динамика**: пики CII = реальные климатические катастрофы (валидация) →
  будущая волатильность ущерба.

### Таблица риска по регионам (на текущее окно 2022)

| Регион | CII | Режим (level) | Основной физический риск |
|---|---|---|---|
| Южная Европа | 88 | HIGH | жара / засуха / пожары |
| Техас | 88 | HIGH | жара / засуха / ураган-наводнение (вне CII) |
| Индия | 57 | MEDIUM | муссон: провал (засуха) / избыток (наводнения) |
| Австралия | 26 | LOW | (после пожаров 2019–20) засушливый режим |
| Глобал (HadCRUT5) | 91 | HIGH | рекордная нестабильность |

### Как применять (ESG)
- **Раскрытие / TCFD**: CII как количественный метрик физического риска портфеля активов;
- **Скоринг активов/локаций**: «зелёные» и «коричневые» регионы по физическому риску;
- **Стресс-сценарии**: HIGH-режим + сезонный SPI → сценарии ущерба для устойчивости цепочки
  поставок и агро;
- **Отчётность**: один one-pager = понятный ответ «как климат влияет на мой портфель».

---

## Честные ограничения (обе аудитории)
1. CII — индекс **режима (36 мес)**, не прогноз даты экстремума;
2. Покрывает жару/засуху/пожары/мороз; **наводнения/ураганы — вне шкалы** (нужна «влажная» шкала);
3. Композитный CII по муссонной **Индии** ловит события слабо — для неё нужна месячная
   SP(E)I-модель муссона, не 36-мес режим;
4. Экономическая связь положительна (сухопутные события), статистически умеренная из-за
   шумных/разномасштабных оценок потерь;
5. Веса компонент равновесные (0.20×5) и калибруются под сектор.

# РЕГИОНАЛЬНЫЙ ОТЧЁТ: CII по регионам (обновлённое ТЗ «Климат.txt»)

Дата прогона: 29.08.2026
Данные: Open-Meteo Historical Weather Archive (суточные: средняя T, сумма осадков), 1940-01 … 2025-02.
Окно 36 мес, шаг 6; веса равновесные 0.20×5.

## Индекс (шаг 1 — регионы, шаг 2 — осадки/засуха)

CII = 0.20·vol + 0.20·trend + 0.20·EVT + 0.20·regime + 0.20·drought_heat

Компонента засухи `drought_heat` (термально-водный стресс):
- **SPI-дефицит**: сезонная нормализация осадков по каждому календарному месяцу
  (SPI; муссонная сезонность не глушит сигнал засухи) — частота×глубина месяцев
  «глубокой засухи» (SPI < −0.8);
- **вклад жары**: частота×величина превышений температуры выше 90-го процентиля.

Региональная нормализация: каждая компонента z-нормируется по своему региону
перед процентильным рангом — единицы разных компонент и климатических типов сопоставимы.

## Валидация и привязка к экономическим потерям (шаг 3)

Пики регионального CII ложатся на документированные катастрофические события:
- **Австралия** — «чёрное лето» 2019–20 (пожары): 98.8-й процентиль; засуха «Миллениум» 2002 — 71.5-й;
- **Техас** — шторм URI 2021 (обвал энергетики, ≈195 млрд USD): 98.8-й процентиль; засуха 2011 — 89.1-й;
- **Южная Европа** — засуха/пожары 2017: 97.0-й процентиль; волна жары 2003 — 57.6-й;
- **Индия** — слабая связь в композите: 2016 (жара) и 2019 (муссон/наводнения) — 13–21-й процентиль;

Событий с ненулевыми потерями: 25 по 4 регионам.
Регрессия log(потери) ~ CII-процентиль: наклон=0.0012, R=0.034 (R²=0.001), p=0.873, Spearman rho=-0.027 (p=0.896).
Робастность без выброса URI-2021 (n=24): R²=0.029, Spearman rho=-0.158.

Модель: события с высоким CII-процентилем сопряжены с крупными потерями;

Событий в топ (CII ≥ 75-й процентиль): 11 из 25.

Типология потерь (важно): CII — индекс жары/сухости/нестабильности.
- Сухопутные события (жара/засуха/пожары/мороз, ~20): положительная связь с CII — высокий CII = крупные сухопутные потери;
- Влажные экстремумы (наводнения/ураганы, ~5): связь отсутствует/обратная — влажный год = низкий CII = большие наводненческие убытки (это вне шкалы CII).
Общая R² ≈ 0 — следствие смеси противоположных типов и шумных оценок потерь;
для полноты нужна отдельная «влажная» шкала (наводнения).

## Выводы и ограничения

1. Региональные адаптеры данных построены (Open-Meteo, без ключа) и отделены от ядра — готовы к подмене на ERA5/Copernicus.
2. Компонента осадков/засухи (сезонный SPI) + региональная нормализация (z-score) сделали единицы компонент и климатических типов сопоставимыми.
3. Муссонная калибровка Индии: засуха теперь меряется по сезону муссона (JJAS) — провал муссона ловится верно (напр., 1987: засуха высокая; 2019-наводнение: низкая), но композитный 36-мес режим по-прежнему ранжирует недавние муссонные экстремумы ниже исторической волатильности середины XX в.; для точечного детекта нужна месячная SP(E)I-модель муссона.
4. Экономика на расширенной выборке (n=25): общая R²≈0 из-за смеси противоположных типов; сухопутные события (жара/засуха/пожары/мороз) положительно связаны с CII (высокий CII = крупные сухопутные потери), влажные (наводнения/ураганы) — вне шкалы CII. Нужна отдельная «влажная» шкала.
5. One-pager для страховых/ESG — `product/CII_One_Pager_Insurance_ESG.md` (андеррайтинг, аккумуляция, страховой индекс потерь/ВВП; ESG: физический риск, TCFD).

# Topo Climate CII — Демо индекса климатической нестабильности

**Открывайте `index.html` в любом браузере (двойной клик, без сервера).**

Готовый демо-пакет для страховых, ESG-фондов, агро, энергетики и городского планирования.

## Что увидит клиент

1. **Интерактивная панель** — динамика индекса CII 0–100 за 1850–2025 (график рисуется в браузере),
   компоненты (волатильность / тренд / EVT / смена режима), региональные карточки.
2. **Главный месседж:** текущий режим глобального климата — **рекордная нестабильность за всю
   историю (90.7 / 100)**, выше пиков El Niño 1997–98 и 2015–16.
3. **Валидация:** пики индекса автоматически ложатся на известные аномалии — то, что продаётся
   заказчикам как доказательство.
4. Региональный слой: Южная Европа, Техас, Индия, Австралия + связь CII с потерями/ВВП и страховой индекс.

## Короткий сценарий презентации

> «Это один индекс 0–100, который показывает, насколько текущий климатический режим региона
> аномален и нестабилен. Сейчас глобально — рекорд всей истории: 91 из 100. Индекс строится из
> волатильности, скорости тренда, тепловых экстремумов и отклонения от доиндустриальной нормы.
> Пики автоматически совпали с El Niño 97–98 и 15–16. Для Южной Европы/Техаса/Австралии есть
> региональные цифры и связь с потерями.»

## Откуда цифры

- Глобал: HadCRUT5, месячная аномалия температуры 1850-01…2025-02 (2102 точки), окно 36 мес.
- Регионы: Open-Meteo (суточная T + осадки, 1940–2025), засуха по сезонному SPI.
- Полные отчёты: `REPORT_global.md`, `REPORT_regions.md`.

---
*Индекс характеризует режим (36 мес), а не отдельный месяц; не является прогнозом погоды.
Региональная экономическая связь положительна, но статистически слаба из-за малой выборки событий.*
